<h1 align="center">Помощник SA</h1>

<p align="center">Оверлей поверх GTA 5 RP для сотрудника полиции: статьи, час задержания и ИИ, который знает законы штата Сан-Андреас (сервер Blaine).</p>

## Что умеет

- **Статьи УК, АК, ДК** — короткие заголовки, клик открывает полный текст с наказанием. Цвета: тюрьма, КПЗ, штраф; метки ФЕД / РЕГ.
- **Умный поиск** — пиши как говоришь: «напал на копа», «пьяный за рулём». Enter — статьи подберёт ИИ.
- **«+» — вменить статью.** Внизу строка для копирования, итог (срок / штраф / КПЗ) и подсказки-лазейки (3 АК → УК 17.4, пороги, повторность…).
- **Избранное** ☆ с фильтрами АК / ДК / УК / ФЕД / РЕГ.
- **Час задержания** с паузами по ст. 20 ч. 2 ПК: адвокат (вызван → едет → приехал → наедине), прокурор, допрос, обыск, видео боло.
- **Готовые ответы адвокату** и Миранда в один клик.
- **ИИ-напарник** — короткая готовая фраза для чата + подсказка. Знает выбранные статьи и все законы, уставы и правила сервера.

## Запуск (Windows)

1. Установи [Node.js](https://nodejs.org) (LTS).
2. Дважды кликни **`Запустить помощника.bat`** — при первом запуске он сам поставит компоненты.
3. В GTA включи режим экрана **«Оконный без рамки»**.
4. Для ИИ: ⚙ → вставь API-ключ с [console.anthropic.com](https://console.anthropic.com). Модель по умолчанию — Haiku 5.5 (дёшево).

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| Alt+S | Поиск статей |
| Alt+Q | Спросить ИИ |
| Alt+1 | Задержал / сброс часа |
| Alt+2 / Alt+3 | Следующий этап адвоката / прокурора |
| Alt+H | Скрыть / показать окно |
| Esc | Вернуться в игру |

## Обновить законы

Тексты законов лежат в `forum/texts`. После их обновления пересобери список статей:

```
node build-articles.js
```

Ключ API хранится только у тебя на компьютере (`%APPDATA%\sa-overlay`), в репозиторий не попадает.
